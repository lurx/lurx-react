# RADAR.md

Things the daily radar surfaced that are worth remembering — parked ideas,
deprecations with a future date, tools to revisit.

Written weekly, in the same PR as the post. The daily radar reads this to avoid
re-surfacing something already logged. Prune it freely; a stale entry is worse
than no entry.

Format:

```
## 2026-09-02
- [BLOG] <thing> — <one line> — <link>
- [LINKEDIN] <thing> — posted / skipped
- [LOG] <thing> — revisit when <condition>
```
